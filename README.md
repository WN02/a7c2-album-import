# A7C2 无线相册导入工具

面向 **索尼 A7C2（ILCE-7CM2）** 的 Windows 收图工具。支持三种连接方式，文件直接落到同一个接收目录，下载完就是最终文件，不需要再「导入一次」。

| 优先级 | 方式 | 适用场景 |
| --- | --- | --- |
| **① 主要方式** | **Wi-Fi 直连（电脑遥控）** | 不插线，电脑直接浏览相机整卡、挑片拉原图，速度最快 |
| ② 备选 | USB 读卡 | Wi-Fi 不可用时，用数据线或读卡器快速挑片复制 |
| ③ 兜底 | FTP 推送 | 相机拍完自动/批量推到电脑，需在相机上配置服务器 |

> **推荐 Wi-Fi 直连**：相机连电脑的移动热点（一跳直连），比经家用路由器快很多；也不需要相机先推送。

---

## 下载

到本仓库右侧 **[Releases](../../releases)** 下载最新的 `A7C2AlbumImport_vX.Y.Z.zip`。

---

## 安装 / 运行

1. **整包解压** zip（不要只把 exe 拖出来）。
2. 进入解压后的 `A7C2AlbumImport\` 文件夹。
3. 双击 `A7C2AlbumImport.exe` 启动，**无需安装 Python 或任何依赖**。

解压后必须保持文件夹结构：`CrAdapter\` 要与 `A7C2AlbumImport.exe` 同级，否则 Wi-Fi 直连功能无法使用。

## 软件界面说明

软件主窗口从上到下分为：**顶部标题栏 → 菜单栏 → 工具栏 → 内容区 → 状态栏**。工具栏和内容区会按当前页面切换：「接收目录」「相机相册（Wi-Fi 直连）」「浏览存储卡（USB）」三页各有自己的工具栏，但顶部标题栏、菜单栏、状态栏始终共用，FTP 后台收图不因切页中断。

### 1. 顶部标题栏

| 元素 | 作用 |
| --- | --- |
| 本机 IP 标签 | 显示电脑局域网 IP，**点击即复制**——相机 FTP 设置里的「主机名」填它 |
| 端口标签 | 显示 FTP 端口（默认 `2121`），**点击可修改** |
| FTP 状态灯 | 圆点 + 文字显示「FTP 在线 / 未运行」，鼠标悬停可看完整地址 |
| **启动服务 / 停止服务** | 一键开/关 FTP 接收服务。开启后相机才能通过 FTP 推送文件；运行时按钮变「停止服务」 |

### 2. 菜单栏

| 菜单 | 项目（快捷键） | 作用 |
| --- | --- | --- |
| **文件(F)** | USB 连接相机…（Ctrl+Shift+O） | 切到 USB 存储卡浏览页 |
| | 无线连接相机 / 返回接收目录（Ctrl+Shift+C） | 在接收目录与相机相册页之间切换（在相机页时文字变「返回接收目录」） |
| | 打开接收目录（Ctrl+O） | 用资源管理器打开接收目录 |
| | 退出（Alt+F4） | 退出程序 |
| **编辑(E)** | 全选（Ctrl+A）/ 反选（Ctrl+I）/ 取消全选（Ctrl+Shift+A） | 接收目录里批量选择文件 |
| | 删除选中文件（Del） | 删除接收目录里选中的文件 |
| | 刷新列表（F5） | 重新扫描接收目录 |
| **设置(S)** | 全部设置…（Ctrl+,） | 打开「设置」窗口（见下） |
| | 目录 | 接收路径设置… / 打开接收目录 |
| | FTP 服务 | FTP 端口… / FTP 账号… / 启动时自动开启 FTP 服务 / 防火墙提示… |
| | 相机 | 相机配置向导… / 无线连接相机（Wi-Fi 直连） |
| | 界面 | 主题（深色/浅色）/ 列表展示 / 显示日志面板 |
| **帮助(H)** | 使用说明（F1） | 打开内置帮助 |
| | 导出诊断包… | 生成脱敏 zip：日志、SDK 版本、网络诊断、能力探针与传输报告，便于排查问题 |
| | 关于 | 版本信息 |

> 「设置」窗口分 5 组：**接收目录**（下载文件最终落点）、**FTP 服务**（端口/账号/安全）、**导出文件命名**（下载后的文件名后缀规则）、**可靠性/诊断与旁路动作**、**外观**（主题等）。

### 3. 工具栏与页面按钮

**接收目录页工具栏**

| 按钮 | 作用 |
| --- | --- |
| 全选 / 反选 / 刷新 | 批量选择与重新扫描（对应编辑菜单的同名项） |
| 列表 ⇄ 平铺 | 切换缩略图展示方式，偏好会被记住 |
| USB连接 | 切到 USB 存储卡浏览页 |
| 无线连接相机 | 切到 Wi-Fi 直连相机相册页 |
| 删除 | 删除接收目录里选中的文件 |
| 打开目录 | 下拉中打开接收目录 |

**相机相册页（Wi-Fi 直连）** — 顶部连接行 + 专用工具栏 + 底部操作区：

| 按钮 | 作用 |
| --- | --- |
| 相机下拉 | 选择已搜索到的相机 |
| 搜索 | 重新搜索同一 Wi-Fi 下的相机 |
| 连接相机 / 断开 | 建立或断开 SDK 连接；断开后可直接「连接相机」重连，无需重新搜索 |
| 高级 ▾ | 展开「访问认证」账号/密码输入框（仅相机开启访问认证时需要，可留空） |
| 重新读取 | 重新枚举整卡，新拍的照片会出现在列表最前面 |
| 体检 | 只读读取 SDK 版本、机型、电量、槽位，不切模式也不删文件 |
| 下载到 + 更改… | 查看/修改相机照片的下载目录（默认「接收目录\camera」） |
| 全选 / 取消全选 / 反选 / 只选未传输 / 筛选… | 底部常驻挑片按钮；「只选未传输」一键挑出还没下载过的 |
| 删除卡内… | 从相机存储卡永久删除选中文件（不可恢复，慎用） |
| 下载选中 | 拉取选中照片的**原图**，进度条显示实时网速 |
| 续跑失败 | 只重试本批失败或停止时尚未下载的文件 |
| 停止 | 中断当前下载 |
| 返回接收目录 | 回到收图页（Esc / Ctrl+Shift+C 也可以） |

**USB 存储卡页** — 专用的工具栏 + 底部操作区，按钮与相机相册页基本一致，区别是：

| 按钮 | 作用 |
| --- | --- |
| 刷新 | 重新枚举已挂载的存储卡 |
| 文件夹… | 没自动识别时手动指定 DCIM 或视频文件夹（选磁盘根/DCIM 会自动带上同卡的视频目录） |
| 无线连接 | 切到 Wi-Fi 直连相机相册页 |
| 删除卡内… / 下载选中 / 续跑失败 / 停止 | 与相机相册页相同；「下载选中」把文件**复制到接收目录、卡内文件保留** |

> 「筛选…」打开组合筛选窗口，可按 **关键字 / 类型（JPG·RAW·视频）/ 传输状态 / 拍摄日期 / 评分 / 保护 / 槽位** 条件挑片，点「重置」清空。

### 4. 内容区与状态栏

- **内容区**：接收目录页显示缩略图网格（单击多选、双击预览，支持「已传输」角标）；下方是**运行日志面板**，可折叠/隐藏。
- **状态栏**：左侧显示「共 N 个文件 · 已选 M 个」和总大小；右侧显示 FTP 接收任务状态（等待相机推送 / 正在接收 N 个 / 本次已收 N 个）和当前接收目录。切到相机页/USB 页时，左侧文字变为「相机相册 · Wi-Fi 直连」或「浏览相机存储卡 · USB」。

## 首次使用：Wi-Fi 直连（主要方式）

### 第 1 步：电脑开移动热点

Windows【设置 → 网络和 Internet → 移动热点】把它打开，记下**网络名称**和**网络密码**（软件【帮助 → 相机配置向导】里可一键打开热点设置）。

> 软件点「无线连接相机」时会**自动检查并开启**电脑移动热点（只开不关，Windows 会在没有设备连接后自行超时关闭）。若自动开启失败，按上面手动开。电脑热点网关一般是 `192.168.137.1`，不用手填。

### 第 2 步：相机连上电脑热点

相机 `MENU → 网络 → Wi-Fi → Wi-Fi 连接：开 → 接入点设置`，选中电脑热点的网络名称，输入第 1 步的密码。

### 第 3 步：确认相机已连上

`MENU → 网络 → Wi-Fi → 显示 Wi-Fi 信息`，看到已连接、IP 为 `192.168.137.x` 即可。软件会自动搜索相机，**相机上不需要手填 IP**。

### 第 4 步：相机打开「电脑遥控」

`MENU → 网络 → 连接/电脑遥控 → 电脑遥控功能 → 电脑遥控：开`。

### 第 5 步：相机必须关掉「FTP 传输功能」

`MENU → 网络 → 传输 / 遥控 → FTP 传输功能 → FTP 功能：关`。

> 它与电脑遥控**互斥**：不关的话软件能搜到相机，但内容传输会失败。

### 第 6 步：访问认证 ID / 密码（因机而异，可留空）

在机身上查：`MENU → 网络 → 网络选项 → 访问身份验证信息`；或看连接电脑遥控时弹出的「访问身份验证信息」。把机身显示的 ID / 密码填进软件「相机相册」页面的「高级 ▾ → 访问认证」输入，凭据只保存在本机设置里。

### 第 7 步：在软件里连接并下载

1. 点工具栏 **「无线连接相机」**（或 `Ctrl+Shift+C`）：主窗口内容直接切成「相机相册」页（不是弹窗），首次进入自动开热点并**只自动搜索一次**相机。
2. 搜到后不会自动连上——在「相机」下拉里选好，自己点 **「连接相机」**（相机上若弹确认请点允许）。
3. 连上后整卡按拍摄时间从新到旧平铺列出，点选卡片（双击 = 只下这一张），「只选未传输」一键挑出还没拉过的。
4. 点 **「下载选中」** 拉**原图**，进度条显示实时网速，可随时「停止」；失败后能用「续跑失败」接着下。下载默认落在 `接收目录` 默认目录下，可在页面顶部「更改…」或者全部设置中修改接受目录。
5. 相机里新拍了照片：点 **「重新读取」**，新拍摄内容会出现在列表最前面。
6. 点「返回接收目录」或按 `Esc` 回到收图页，FTP 接收全程在后台运行。

### 连不上 / 下载没动静

让相机退出回放或菜单、回到拍摄待机画面；把相机彻底关机再开机，重新打开「电脑遥控」，并确认 FTP 功能仍为关；仍不行就先用上面的 USB 方式取文件。

> 断开后点「连接相机」可**直接重连**，不需要先搜索；万一相机换了 IP，会自动重搜并按 IP 对号重连。

## 备选：USB 读卡

Wi-Fi 不可用时用这条：

1. 相机 `MENU → 网络 → USB → USB 连接` 设为 **Mass Storage**，或把卡插进读卡器。
2. 软件点 **「USB连接」**（或 `Ctrl+Shift+O`），自动列出存储卡。
3. 自动扫描 `DCIM`（照片）+ `PRIVATE\M4ROOT\CLIP` 等（视频）目录——索尼视频不在 DCIM，本工具会自动一并扫描。
4. 挑片 → **「下载选中」** → 复制到接收目录，按拍摄时间重命名，卡内文件保留。

> 没自动识别时点「选择文件夹…」手动指定。双卡机型在 Mass Storage 下通常只挂载 Slot 1。MTP / PC Remote 模式不挂磁盘，USB 浏览不支持。

## 兜底：FTP 推送

相机连上与电脑**相同的路由器 Wi-Fi**，且同网段：

1. `MENU → 网络 → 传输 / 遥控 → FTP 传输功能`：FTP 功能 **开**。
2. 服务器设置 → 服务器 1：主机名填**电脑 IP**、端口 `2121`、安全协议 **关**、被动模式 **开**、**目录设置填 `/`**（不是 `/incoming`）。
3. 用户信息填【设置 → FTP 服务】里的账号 / 密码（每台机器随机生成）。
4. `MENU → FTP 传输` 选择发送。

> FTP 功能与 Wi-Fi 直连的「电脑遥控」互斥，只能开一个。

## 常见问题

**双击 exe 没反应 / SmartScreen 拦住**
程序未签名，点「更多信息 → 仍要运行」；杀软误报同理加入白名单。

**Wi-Fi 直连搜不到 / 报 `没有搜索到相机`**
确认相机「电脑遥控」为开、FTP 功能为关；相机退出回放/菜单回到待机画面；必要时关机重启相机。注意软件只自动搜索一次，没自动连上时要自己点「连接相机」。

**USB 看不到视频**
索尼把视频放在 `PRIVATE\M4ROOT\CLIP`（XAVC S/HS）、`PRIVATE\AVCHD\BDMV\STREAM`（AVCHD）等目录，不在 DCIM；本工具已自动一并扫描。

**MP4 缩略图是占位图**
装了 `ffmpeg` 并在 PATH 中才会抽首帧，不影响文件本身下载。

**Wi-Fi 直连报缺 SDK**
从索尼官网下载 Camera Remote SDK，把 `Cr_Core.dll` 和 `CrAdapter\` 放到 exe 同级目录。

**FTP 收不到图**
防火墙放行 `2121` + 被动 `50000–50099`；【设置 → FTP 服务】里可复制放行命令；账号密码与相机侧完全一致；目录设置为 `/`。

## 数据与隐私

所有设置、接收目录、日志、已传输记录都保存在本机 `%LOCALAPPDATA%\A7C2AlbumImport\`，不随程序包传播；FTP 口令每台机器首次启动随机生成。
